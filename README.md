### 🌟 أبرز مميزات تجربة الهاتف الذكي (Mobile Innovations):

1. **🛸 شريط التنقل السريع العائم الذكي (Floating Mobile Quick Dock):**
   - شريط زجاجي سيبراني عائم ومثبت أسفل شاشة الهاتف بتأثير Glassmorphism نيون.
   - يتيح التنقل الحر والفوري بإصبع الإبهام (One-Thumb Navigation) بين:
     - 🏠 **الرئيسية (Home)**
     - 💼 **المشاريع والخبرات (Projects)**
     - 📰 **المقالات الهندسية (Articles)**
     - 🎓 **الدورات والكوبونات (Teachings)**
     - ☰ **القائمة الكاملة (Full Menu)**
   - يدعم المزامنة اللحظية (Live Active State Sync) مع القسم المعروض حالياً ونقطة نيون مضيئة تفاعلية.

2. **🌀 القائمة السائلة التفاعلية (100dvh Liquid Glass Drawer):**
   - تغطية كاملة ودقيقة للشاشة بارتفاع ديناميكي `100dvh` (Dynamic Viewport Height) لمنع أي تشوه عند ظهور أو اختفاء شريط المتصفح.
   - ترويسة أنيقة بشعار الموقع وزر إغلاق صريح وبارز `(✕)`.
   - كروت تنقل شبكية منظمة ومزودة بأيقونات وتأثيرات ظهور تتابعية متدرجة (Staggered Animations).
   - قفل تلقائي لتمرير الصفحة خلف القائمة لمنع التداخل.

3. **👆 إيماءات اللمس الذكية متعددة الاتجاهات (Multi-Directional Gestures):**
   - إمكانية إغلاق القائمة بالسحب السريع للأعلى أو لليمين/اليسار بسلاسة تامة.
   - إزالة تأخير النقر (300ms Tap Delay) عبر خاصية `touch-action: manipulation`.
   - استجابة فيزيائية لمسية فورية (Tactile Active Press Effect) لجميع الأزرار والكروت.

4. **🔝 زر الصعود الذكي مع مؤشر القراءة الدائري (Scroll-To-Top Circular Progress):**
   - زر عائم دائري يظهر تلقائياً عند التمرير لأسفل.
   - حلقة SVG دائرية متوهجة تحسب نسبة قراءة وتصفح الصفحة بدقة متناهية وترتفع مع التمرير.
   - صعود انسيابي سلس وفوري لأعلى الصفحة بنقرة واحدة.

5. **🛹 شريط الفلاتر الأفقي الانسيابي (Touch-Swipe Filter Carousel):**
   - تحويل فلاتر المقالات والدورات على الهاتف إلى شريط كبسولات أفقي قابل للتمرير بالسحب والانزلاق باللمس (`-webkit-overflow-scrolling: touch`).
   - استقرار سلس ومحاذاة تلقائية (Scroll Snap) للكبسولة النشطة دون تشويه واجهة المستخدم.

6. **📐 تكيف مطلق مع جميع مقاسات الشاشات (280px إلى Foldables و Tablets):**
   - طباعة خطوط مرنة وحيوية باستخدام دالة `clamp()` الرياضية لجميع العناوين والنصوص.
   - كروت شبكية ذكية `minmax(min(100%, 280px), 1fr)` تضمن عدم خروج أي كارت عن حدود الشاشة إطلاقاً مع انعدام تام لأي تمرير أفقي جانبي عرضي.
   - احترام حواف الشاشات الآمنة للهواتف الحديثة والـ Dynamic Island والنوتش (`env(safe-area-inset-*)`).

7. **⚡ تسريع المعالجة الرسومية وثبات الإطارات (60-120fps Smoothness):**
   - استخدام `transform: translate3d(0,0,0)` و `will-change` لتفعيل تسريع العتاد (GPU Acceleration).
   - تخفيف حسابات جزيئات Three.js ثلاثية الأبعاد بذكاء على الهواتف لتوفير البطارية وضمان أعلى معدل إطارات سلس.

## 🔥 التحديثات الجديدة الشاملة | Latest Major Updates

### 1️⃣ شريط التنقل العائم والتنقل الحر (Floating Quick Dock)
* شريط تنقل سفلي عائم بلمسات نيون مستقبلية يتيح الوصول المباشر لكافة أركان الموقع دون الحاجة للتمرير لأعلى الصفحة.
* تأثيرات تفاعلية استثنائية مع دعم التبديل الفوري بين اللغتين العربية والإنجليزية.

---

### 2️⃣ منظومة النسخ والمشاركة الذكية (Smart Copy & Rich Sharing)
* **📋 إشعار النسخ الغني (Rich Share Preview Toast):**
  * عند النقر على زر النسخ أو المشاركة في أي مقال أو دورة، يتم فوراً نسخ الرابط إلى الحافظة، مع ظهور **Toast تفاعلي فاخر** أسفل الشاشة يحتوي على:
    * صورة مصغرة للمحتوى (Image Thumbnail)
    * عنوان المقال/الدورة والملخص (Title & Summary)
    * زر فتح الرابط مباشرة وزر مشاركة أصلي.
* **⚡ دعم Web Share API الأصلي:**
  * مشاركة سلسة وتلقائية مع تطبيقات الهواتف الذكية (WhatsApp, Telegram, Facebook, Twitter/X, LinkedIn) بضغطة زر واحدة.
* **🎟️ نسخ أكواد الكوبونات:**
  * إمكانية نسخ كود الخصم (Coupon Code) بنقرة واحدة مع توضيح مدة الصلاحية والمقاعد المتاحة.

---

### 3️⃣ عارض الوسائط والصور المتقدم (Image & Media Engine)
* **🖼️ نظام إدارة الصور الذكي والبدائل الفاخرة (Fallback Images):**
  * معالجة تلقائية لأي رابط صورة غير متاح أو تالف عبر بدائل صور ذهبية وسماوية فائقة الجودة (`FALLBACK_ARTICLE_IMAGE` & `FALLBACK_TEACHING_IMAGE`).
  * تحسين تحميل الصور بتنسيق الكروت والـ Lazy Loading لتسريع استجابة الصفحة.
* **🎥 مشغلات الفيديو التفاعلية المدمجة (Smart Auto-Embedder):**
  * تحويل الروابط تلقائياً داخل نصوص المقالات والدورات إلى مشغلات تفاعلية مباشرة تشمل:
    * 🔴 **YouTube** (الفيديوهات العادية ومقاطع Shorts)
    * ⚫ **TikTok** (مشغل التيك توك المباشر)
    * 🟣 **Instagram** (المنشورات والـ Reels)
    * 🔵 **Facebook Videos & Watch**
    * 🐦 **Twitter / X** Tweets
    * 🧵 **Threads** Posts
    * 🎬 **Vimeo** Player
    * 🎓 **Udemy Course Preview Cards**
* **📐 المعادلات الرياضية والرموز العلمية (MathJax):**
  * دعم كامل لتصيير المعادلات والرموز الهندسية والفيزيائية بتنسيق LaTeX بدقة عالية داخل المقالات.

### 4️⃣ صفحات التفاصيل والروابط التفاعلية (Details & Dynamic Routing)
* **📄 قارئ المقالات المخصص (`articles/?id=...`):**
  * صفحة مخصصة لقراءة المقال بالكامل مع عداد التاريخ، الوسوم (Hashtags)، التصنيف، أزرار الطباعة، والمشاركة.
  * دعم كامل للتنقل الفوري وتغيير اللغة (عربي / إنجليزي) والوضع المظلم دون إعادة تحميل الصفحة.
* **🎓 صفحة تفاصيل الدورات والندوات (`teaching-details/?id=...`):**
  * استعراض تفاصيل المحاضرات، المدة الزمنية، تقييمات الطلاب، الأسعار، وأكواد الخصم التفاعلية.
* **🛡️ عارض البيانات الهولوغرافي الآمن (Holographic Data Vault):**
  * استعراض ملفات السيرة الذاتية (CV)، الشهادات، وملفات Google Drive داخل نافذة عائمة ثلاثية الأبعاد بتأثير زجاجي دون مغادرة الموقع.

### 5️⃣ محرك بايثون وتوليد المعاينات (Python Automation Engine)
ملف الأتمتة الرئيسي: [`generate_share_pages.py`](generate_share_pages.py)

```mermaid
graph TD
    A[articles.json / teachings.json] -->|Python Generator| B(generate_share_pages.py)
    B -->|1. تلخيص وتخفيف البيانات| C[articles-summary.json]
    B -->|2. توليد صفحات المعاينة| D[articles/article-*.html]
    B -->|3. توليد صفحات الدورات| E[teaching-details/teaching-*.html]
    C -->|تحميل فائق السرعة| F[الموقع الرئيسي & الفلاتر]
    D & E -->|Open Graph Meta Tags| G[معاينات السوشيال ميديا: واتساب، فيسبوك، إكس]
    G -->|Instant JS/Meta Redirect| H[قارئ المقالات والدورات]
```

* **⚡ تقليص حجم البيانات بنسبة > 90%:**
  * إنشاء ملف `articles-summary.json` الخفيف لتغذية شبكة الكروت في الصفحة الرئيسية والبحث بسرعة هائلة وتوفير الباندويث.
* **🌐 صفحات مشاركة ثابتة ببطاقات Open Graph كاملة:**
  * توليد ملف HTML مستقل لكل مقال (`articles/article-{id}.html`) وكل دورة (`teaching-details/teaching-{id}.html`).
  * تزويد كل صفحة بوسوم `og:image`, `og:title`, `og:description`, `twitter:card`, وبيانات `Schema.org Article JSON-LD`.
  * تحويل فوري تلقائي للزائر (Instant Redirect) لقارئ المقال الفعلي لتجربة تصفح متكاملة.

## 🚀 تشغيل وتوليد الصفحات | How to Run & Generate

### 1. تشغيل الموقع محلياً:
يمكنك فتح `index.html` مباشرة أو تشغيل سيرفر محلي خفيف:
```bash
# باستخدام بايثون
python -m http.server 8000
```
ثم توجه إلى المتصفح عبر الرابط: `http://localhost:8000`

### 2. تحديث وتوليد صفحات المشاركة والملخصات:
عند إضافة مقالات جديدة في `articles.json` أو دورات جديدة في `teachings.json`، قم بتشغيل اسكربت بايثون:
```bash
python generate_share_pages.py
```
**المخرجات الناتجة تلقائياً:**
- ✅ تحديث `articles-summary.json` فائق السرعة.
- ✅ توليد جميع صفحات `articles/article-{id}.html` لشبكات التواصل.
- ✅ توليد جميع صفحات `teaching-details/teaching-{id}.html` للكوبونات والدورات.
